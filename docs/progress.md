# 進捗

現在：探索・接近・停止をユーザーの手元で動作確認済み。次は複数配置での評価と結果記録の設計。

## 確認の区切り

ユーザーの手元での確認後に次へ進む。

| 段階 | 確認内容 | 状態 |
|---|---|---|
| 0 | 設計とパッケージ名 | 承認済み |
| 0a | 文書とPython設定 | 承認済み |
| 1 | モデルと床の表示、再開・終了 | コード承認済み。通常入口での立位表示を確認済み |
| 2 | 立位維持・前進・旋回・停止 | 立位・前進・旋回・停止を手元で確認済み |
| 3 | 対象物とロボット視点カメラ | 手元で動作確認済み |
| 4 | 対象の検出と検出結果の表示 | 手元で動作確認済み |
| 5 | 探索・接近・停止 | 手元で動作確認済み。配置別の定量評価は未実施 |
| 6 | 評価・動画・レポート・再現手順 | 未着手 |

## 検証

- 素材・起動・方策・物理・カメラ・検出・行動判断を含む77テストが通過。Ruffのlint・formatとdiffチェックも通過。
- 検出の継続確認、旋回方向、中央許容幅のヒステリシス、見失い直後の停止と探索復帰、距離不明時の停止、到着保持、60秒の時間切れ、手動解除、Rでの再初期化を検証。
- 既知寸法と画角からの距離推定、画像端で欠けた対象の距離不明判定、CLIの自動モード条件と有限座標の確認を実施。
- 実際のMuJoCo物理とONNX方策を使い、GPU描画だけを立方体の投影RGB画像へ置き換えた統合テストを実行。正面・左・右・背後でARRIVEDに到達し、その後3秒の立位維持と指令ゼロを確認。対象が映らない画像では60秒でTIMED_OUTとなり停止を維持。
- 投影画像の試行：到着判定は正面5.2秒・左7.5秒・右13.5秒・背後9.8秒。停止3秒後の実カメラ−対象中心距離は約0.55〜0.60 m。推定40 cmは実距離40 cmを保証しない。投影画像は照明・遮蔽・レンズメッシュを再現しておらず、実描画による精度・成否の評価とは区別する。
- 投影画像で状態・推定距離・動作理由の表示を目視確認。既存の移動・立位・表示更新・描画遅延対策のテストも通過。
- 実際の頭部画像を使った自動動作はユーザーの手元で確認済み。エージェント環境では描画接続エラーにより実画像評価を実行できない。

## 次の確認対象

正面・左右・背後の配置ごとに、実画像での成否・所要時間・停止距離・停止後の安定性を記録する。到着判定と実際の停止結果を分けて評価し、結果を確認してから動画・レポートの作成へ進む。
