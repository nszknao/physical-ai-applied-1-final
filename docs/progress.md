## 検証

- Python 3.12.7、MuJoCo 3.10.0、ONNX Runtime 1.31.0、BAM 1.0.1（固定Git revision）を使用。導入済み `.venv/bin/python` で検証。
- 素材取得・起動・方策・BAM・移動・カメラ・保存形式を含む42テストが通過。Ruffのlint・formatとdiffチェックも通過。
- 実方策の30秒立位：最低胴体高さ0.1147 m、最大傾き0.51度、最大水平ずれ0.0027 m。前進・左右旋回・停止・リセットの既存試験も通過。これらのGUI操作はユーザーが確認済み。
- 独自シーンはnq=21、nv=20、actuators=14を維持し、2秒立位が成功。固定対象の配置・カメラの前方と上下左右・接近時の投影拡大・旋回による視野外への移動を数値検証。
- カメラのnear clip以遠から対象へのrayが対象に直接当たることを、初期姿勢と2秒立位後に確認。レンズのメッシュはカメラ直前にあるがnear clip内。
- カメラ取得前の姿勢更新を10 Hzで挟んだ前進と、挟まない前進で、関節位置・速度・方策の履歴が完全一致。テストではrendererをモックしており、GPU描画は検証していない。
- 公開APIの属性名を `viewer.perturb` に修正。実際のMuJoCo Handleを使うテストで修正前の起動エラーを再現し、頭部・外部追従の両視点で修正後の初期化と1回の更新・終了を確認。ウィンドウとGPU描画はモック。
- PPMのRGB順・行順・保存先作成を検証。合成画像のPPMをmacOSのsipsでPNGへ変換できることも確認。
- エージェント環境ではCGLが `invalid CoreGraphics connection` で失敗。代替のDocker接続も利用できず、エージェントによる実画面の確認と描画性能の計測は未実施。ユーザーから手元での動作確認済みとの報告あり。
